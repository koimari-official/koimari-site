# こいまり新トップ（試作）— fruit-top

2026-10-23作成。オーナー指示：A（わざわざ行く店の型）・B（ホームページの強化）・C-1（お取り寄せの入口）を準備。D（客単価アップ）は画像を入れたら出せるように。**今のページは上書きしない。**

- 試作ページ：`index-fruit.html`（検索に出さない）。いまのトップ `index.html` は一切書き換えない。
- 組み立て：`python fruit-top/make_fruit_top.py`。index.html を読み込んで作るので、index.html が更新されたら実行し直す（いまのトップの欄が増減すると、黙って作らずに止まって知らせる）。
- 部品：`sections/*.html`（新しい欄）、`fruit-top.css`（見た目。色・書体はいまのサイトの設定をそのまま使う）、`fruit-top.js`（動き。GSAP）、`img/`（写真は「広告・宣伝活動」の元ファイルをそのままコピー。解像度は変えていない。出典は `img/sources.json`）。
- 設定：`config.json`
  - `baseShopUrl`：BASEのURLを入れると「お取り寄せ」が4か所（最初の画面のボタン・目的別のタイル・「おうちでこいまり」欄・スマホの固定ボタン）に出る。空なら出ない。
  - `upsell.sizes / options / gifts`（D）：`image` に `fruit-top/img/` のファイル名を入れた項目だけ出る。全部空なら欄ごと出ない（設定にない画像・文言・価格は出さないルール）。号数と人数の目安・オプション名は、予約フォーム（member.html）の表記と同じ。金額は載せない（予約フォームで計算される）。
- 並び：新しい最初の画面は、いまの最初の画面（#hero・表示だけ隠す）の位置に置く。宣伝の帯（クーポン・フェア）とヘッダーは、いまと同じくその下に続く。
- 隠している欄：お品書き・砂糖菓子・過去のケーキ集・こだわり・SNSのご案内（HTMLは残し、表示だけ隠す＝読み込みの処理を止めない）。スマホでは丸い「ご予約」ボタンも隠し、画面下の固定ボタンに一本化。
- 和柄：青海波（Wikimedia Commons「Seigaiha.svg」・Public domain）。
- 本番にするとき（オーナーのOK後）：index.html を退避してから、make_fruit_top.py の出力を index.html にする（検索に出さない指定と「（新トップ試作）」を外す）。管理画面の「ヒーロー画像」は新しい最初の画面では使わない点を、事前にオーナーに伝える。
